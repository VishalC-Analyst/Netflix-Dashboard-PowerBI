# Netflix Content Insights Dashboard (Power BI)

Power BI dashboard analysing Netflix content, production peaks and release trends across 5.8K+ titles.

## Objective
- Understand the movie vs TV show mix in Netflix's catalogue
- Identify genre leaders and content release trends over time
- Give a geographic view of where subscribers are concentrated

## Approach
- Cleaned and modelled the titles dataset in Power BI
- Built KPI cards for total runtime, movie count and TV show count
- Created time-series analysis of content released by year (2000 onwards)
- Added an Azure Maps visual for subscribers by country
- Added Title, Genre and Year slicers so users can filter the whole report

## Key Findings
- **Movie-heavy catalogue:** 3,759 movies vs 2,047 TV shows (64.7% vs 35.3%)
- **Peak output in 2019:** 540 movies and 308 shows released that year, after sharp growth from 2015
- **Genre leaders:** Comedy leads (407 movies, 103 shows), followed by drama (240 / 110) and documentary (225 / 95)
- **Total runtime:** 7,513 hours of content
- **Key markets:** The US and India show the largest subscriber bubbles on the map

Power BI Desktop, Azure Maps visual
